📋 Survey Question Import Formats (.docx / .txt)

You can create questions in Microsoft Word (.docx) or Notepad (.txt) and dump all 3 types directly.

💡 No correct answers required: In survey exams, questions do not need answers specified. Option-based questions can have any number of options (e.g. 2, 3, 4, 5, 6, 7+).
1. Single Option Selection (MCQ) Type: MCQ 
1. How would you rate the overall quality of campus laboratory facilities?
Type: MCQ
a) Excellent - Modern equipment & well maintained
b) Good - Adequate facilities
c) Average - Needs periodic updates
d) Needs Immediate Improvement
2. Multiple Options Selection (Multi Select) Type: Multi Select 
2. Which technical workshops or certifications are you interested in pursuing?
Type: Multi Select
a) Full Stack Web Development (React & Node.js)
b) Artificial Intelligence & Machine Learning
c) Cloud Architecture & DevOps (AWS / GCP / Docker)
d) Cybersecurity & Ethical Hacking
e) Data Science & Big Data Analytics
f) Mobile Application Development (Flutter / Android)
3. Written Response (Text) Type: Text 
3. What constructive suggestions or ideas do you have to improve student learning experiences?
Type: Text
